# Drag and Drop from a modeless dialog into AutoCAD editor

发布日期: 2015-04-01

原始链接: https://adndevblog.typepad.com/autocad/2015/04/drag-and-drop-from-a-modeless-dialog-into-autocad-editor.html

## 文章内容

By Balaji Ramamoorthy
ObjectARX 2004 had a nice C++ sample that demonstrates the implementation of drag-drop into AutoCAD both as files from the explorer and from a modeless dialog inside AutoCAD. I have attached the migrated sample for AutoCAD 2016. To try it, appload the arx and run "arxdd" command. Please follow the ReadMe.txt included in the sample for explanation on the methods implemented to enable drag and drop.
Download Arxdd
