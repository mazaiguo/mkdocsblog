# Autodesk Cloud Accelerator update

发布日期: 2015-04-01

原始链接: https://adndevblog.typepad.com/autocad/2015/04/autodesk-cloud-accelerator-update.html

## 文章内容

Autodesk recently finished the first ever Cloud Accelerator where several companies were selected to come into the San Francisco office to work on their applications, which use the Autodesk cloud technology in some way.  They were able to work directly with the ADN and cloud teams to accelerate the development of their applications. 
The first event was so successful, there has been another one scheduled for June 1-12.  The deadline for applications is April 19th, so it’s quickly approaching. Visit Autodesk Cloud Accelerator for more information.
