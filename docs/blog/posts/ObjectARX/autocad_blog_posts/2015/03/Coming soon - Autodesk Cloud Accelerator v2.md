# Coming soon - Autodesk Cloud Accelerator v2

发布日期: 2015-03-01

原始链接: https://adndevblog.typepad.com/autocad/2015/03/coming-soon-autodesk-cloud-accelerator-v2.html

## 文章内容

By Stephen Preston


Following the huge success of our inaugural Autodesk Cloud Accelerator program earlier this month, we're now in the planning stages for Cloud Accelerator v2. This will be held in our San Francisco office from June 1st to June 12th 2015. The format will be the same as the first - if you have an idea for an application you can build using any Autodesk Cloud Platform API, then you're eligible to apply.
Our Accelerator website (autodeskcloudaccelerator.com) will be updated very soon with the new Call for Proposals, but you’re welcome to email <adn-training-worldwide@autodesk.com> as soon as you like with a  proposal. The deadline for proposals will be April 19th 2015.
To maximize your chance of success, bear in mind that the two main criteria we’ll be evaluating your proposal against are:
Can the proposed workflow be achieved using the Autodesk API in its current state – we’ll be looking for evidence in your proposal that you’ve already evaluated the capability of the Autodesk API you want to use.
Could the application developed during the Accelerator go on to become a commercial product (or a component of an existing commercial product).
