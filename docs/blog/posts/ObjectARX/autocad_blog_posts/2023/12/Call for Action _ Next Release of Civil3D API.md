# Call for Action : Next Release of Civil3D API

发布日期: 2023-12-01

原始链接: https://adndevblog.typepad.com/autocad/2023/12/call-for-action-next-release-of-autocad-civil3d.html

## 文章内容

By Madhukar Moogala
We are happy to announce that we have released beta version of next release of Civil3D.
Please refer to our previous post on AutoCAD API!
Civil3D beta now supports .NET 8.0

To get the latest Beta, please sign in to Autodesk Feedback Portal
From the landing page, browse for `Downloads` from the top Menu.
For discussions on API migration please post your queries on Feedback Portal
Select `Feedback` dropdown menu, select `User Forums` .
For problem reports please use `Submit` button on the landing page.
