# Call for Action : Next Release of AutoCAD API

发布日期: 2023-08-01

原始链接: https://adndevblog.typepad.com/autocad/2023/08/call-for-action-next-release-of-autocad.html

## 文章内容

By Madhukar Moogala
Next Release of AutoCAD API, AutoCAD 2024 + 1 will be planning to support NET Core technology.



We have released an alpha on our feedback portal.
Note :
AutoCAD alphas is targeted to support NET 6.0
AutoCAD betas and the final release is targeted to support NET 8.0.
For more update refer AutoCAD Customer Council in the Feedback Community.
Our team is actively monitoring the AutoCAD Customer Council to onboard new developers to Beta portal, so if this is first time please join  https://feedback.autodesk.com/key/AutoCADBeta
Once you join, go to Downloads section to find getting started material and information about ObjectARX SDK.

If you are ADN subscription partner you can find getting started material in  ADN Portal as well.  
https://adn.autodesk.io/
Please go to Software\Beta Portal


Here is a guide to enrol yourself  into Autodesk Feedback community and more details about the program.
- https://forums.autodesk.com/t5/autodesk-community-voices/autodesk-feedback-community-how-to-get-involved-in-the/ba-p/10902496
