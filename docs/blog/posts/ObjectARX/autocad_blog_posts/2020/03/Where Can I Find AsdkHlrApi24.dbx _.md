# Where Can I Find AsdkHlrApi24.dbx ?

发布日期: 2020-03-01

原始链接: https://adndevblog.typepad.com/autocad/2020/03/where-can-i-find-asdkhlrapi24dbx.html

## 文章内容

By Madhukar Moogala
From AutoCAD 2021, the module is removed from ObjectARX SDK’s redistribute directory and is included as part of AutoCAD 2021.
You can find the module at your AutoCAD installation directory, at my end
It is found at
"C:\rogue\AutoCAD 2021\AsdkHlrApi24.dbx"
And, typically I user `where` search tool for quickly finding the modules or files etc, `where` Windows CLI in-built tool.

Another tool I use is `es`, a free CLI utility from VoidTools which is lightening fast
Note: I’m now way endorsing or have any relationship with VoidTools, it is my experience using the tool over a long period.
