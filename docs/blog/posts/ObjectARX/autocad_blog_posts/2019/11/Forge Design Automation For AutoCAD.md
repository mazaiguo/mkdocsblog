# Forge Design Automation For AutoCAD

发布日期: 2019-11-01

原始链接: https://adndevblog.typepad.com/autocad/2019/11/forge-design-automation-for-autocad.html

## 文章内容

By Madhukar Moogala
There is still time to get hands on with the new Design Automation APIs. Four webinars are scheduled in December that will cover each of the Design Automation APIs in depth. The recordings will be posted after so be sure to register to take advantage.

December 5 - Design Automation API for AutoCAD on Forge
Time: 8:00 AM Pacific Standard Time
Albert Szilvasy, software Architect will share details about the new and updated API.
In this webinar, we will discuss how the Design Automation for AutoCAD empowers customers and partners to get more work done more quickly, reliably and collaboratively using cloud-based web services. We will demonstrate the ability to run scripts on your design files, leveraging the scale of the Forge Platform to automate repetitive tasks.

Register Now


There are webinars on other Engines too, like Revit etc., please do check our Forge Blog for more information. 
Update:
Those who missed webinar, Albert Szilvasy, Senior Software Architect, gave an overview and demos of Design Automation API for AutoCAD on Forge API.
It is available on YouTube now, please check it out.
