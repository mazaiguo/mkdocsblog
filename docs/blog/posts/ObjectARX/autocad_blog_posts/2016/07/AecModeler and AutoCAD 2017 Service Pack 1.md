# AecModeler and AutoCAD 2017 Service Pack 1

发布日期: 2016-07-01

原始链接: https://adndevblog.typepad.com/autocad/2016/07/aecmodeler-and-autocad-2017-service-pack-1.html

## 文章内容

By Virupaksha Aithal
There was an issue with hideDisplay API of Body class in AecModeler in AutoCAD 2017. below is the updated module.
AecModeler for AutoCAD 2017 SP1
To install this update
1. Close all software applications.
2. Navigate to the folder where your Autodesk product is installed.
C:\Program Files\Autodesk\AutoCAD 2017
3. Right-click AecModeler.dbx and rename it as AecModeler.bak.
4. Download the files to a location on your local computer.
5. Copy the downloaded file (AecModeler.dbx) (from the 32-bit or 64-bit sub-folder depending on whether you have 32-bit or 64-bit software) to your product installation folder

To remove this update
1. Close all software applications.
2. Navigate to the folder where your Autodesk product is installed,
C:\Program Files\Autodesk\AutoCAD 2017
3. Delete AecModeler.dbx (the file you downloaded and installed).
4. Rename AecModeler.bak to AecModeler. dbx
