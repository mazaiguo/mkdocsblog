# Hotfix : AsdkHlrAPI–ObjectARX 2017

发布日期: 2016-05-01

原始链接: https://adndevblog.typepad.com/autocad/2016/05/hotfix-asdkhlrapiobjectarx-2017.html

## 文章内容

By Madhukar Moogala
The following issue is addressed by this fix:
Incorrect scaling  and positioning of the projection generated by HLR API.
  The hotfix can be downloaded from here
Link contains following directory structure
+---x64
|   |   N052.10.DID_TFS_129787_AsdkHlrAPI21.dbx.md5
|   |   N052.10.DID_TFS_129787_AsdkHlrAPI21.dbx.tag
|   |
|   +---Binaries
|   |   \---ACAD
|   |           AsdkHlrApi21.dbx
|   |
|   \---Symbols
|       \---ACAD
|               AsdkHlrApi21.pdb
|
\---x86
    |   N052.10.DID_TFS_129787_AsdkHlrAPI21.dbx.md5
    |   N052.10.DID_TFS_129787_AsdkHlrAPI21.dbx.tag
    |
    +---Binaries
    |   \---ACAD
    |           AsdkHlrApi21.dbx
    |
    \---Symbols
        \---ACAD
                AsdkHlrApi21.pdb
Instructions:
Locate AsdkHlrApi21.dbx in <SDK folder>\Redistrib-x64
Rename AsdkHlrApi21.dbx to AsdkHlrApi21.dbx.old
Copy binary from relevant platform folder and paste.
