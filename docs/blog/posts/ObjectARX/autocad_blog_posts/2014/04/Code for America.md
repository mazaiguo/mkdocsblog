## 文章内容

By Stephen Preston
Earlier this week I drove in to San Francisco to attend a meetup for the 'SF Developer Advocates' group - my first visit to this group. The meeting itself was interesting - there were about 15 'developer advocates, so it was easy to talk to everyone. But the reason I'm mentioniong it on this blog isn't for the meetup, its for the organizers.
The meetup was hosted by Code for America - a non-profit organization that helps programmers write code that helps their local communities (and encourages cities to expose data that those programmer scan use). I think this is a great idea, so the least I could do is give them a mention on DevBlog.
