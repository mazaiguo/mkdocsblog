# Autodesk AutoCAD I/O

发布日期: 2014-11-01

原始链接: https://adndevblog.typepad.com/autocad/2014/11/autodesk-autocad-io.html

## 文章内容

By Virupaksha Aithal
AutoCAD I/O API is HTTP (REST) API set that enables applications to query, create, update, project, and transform DWG content. AutoCAD I/O API is in beta stage now. We invite you to try it out and give us feedback!  This new API enables AutoCAD’s core functionality in a web service environment.
If you are not yet engaged with the Beta, please go to our Developer Center to request an API key.  You will also find documentation of the API there. 
Please use forum http://forums.autodesk.com/t5/autocad-i-o/bd-p/105  to report problems, share samples and ideas regarding the use of this API, and to ask for help.
Useful links:
Developer Center = http://developer.autodesk.com
Documentation = http://developer.api.autodesk.com/documentation/v1/acad_io/index.html#acad-io-api-reference
GitHub repository for samples = https://github.com/Developer-Autodesk/AutoCAD.io
