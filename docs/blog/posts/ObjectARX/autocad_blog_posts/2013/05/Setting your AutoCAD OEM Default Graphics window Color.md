# Setting your AutoCAD OEM Default Graphics window Color

发布日期: 2013-05-01

原始链接: https://adndevblog.typepad.com/autocad/2013/05/setting-your-autocad-oem-default-graphics-window-color.html

## 文章内容

by Fenton Webb
You might need to set the AutoCAD Drawing Window color (Model Space Background) to a different color via your installer. To do so is pretty easy – simply set your OEM registry key .\Profiles\<<Unnamed Profile>>\Drawing Window\Background setting to the desired DWORD value.
