# Reliable Identifier/GUID for a P&ID Project

发布日期: 2013-01-01

原始链接: https://adndevblog.typepad.com/autocad/2013/01/reliable-identifierguid-for-a-pid-project.html

## 文章内容

By Fenton Webb
If you are looking for a unique P&ID project GUID, as of 2013 Plant3d the PnPDatabase.DbId() is the best way to go.
Note: that if you copy the whole project to a new location this GUID will *not* change.
