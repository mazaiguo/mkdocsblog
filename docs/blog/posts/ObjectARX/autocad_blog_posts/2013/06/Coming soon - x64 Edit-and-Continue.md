# Coming soon - x64 Edit-and-Continue

发布日期: 2013-06-01

原始链接: https://adndevblog.typepad.com/autocad/2013/06/coming-soon-x64-edit-and-continue.html

## 文章内容

By Stephen Preston
Last November, I encouraged you all (yawl?) to vote on the Microsoft Uservoice site for the 'x64 edit and continue' request.
Good News! Today, I (and all my DevTech colleagues) received an email confirming that this will become available (relatively soon) in Visual Studio 2013:
Well - mostly good news - this is for VB.NET and C# only. The request for C++ is still open.
Nevertheless, all of us who voted for this should take a moment to pour a celebratory glass of Mountain Dew Code Red, smile smugly, and congratulate ourselves for our powers of persuasion and general awesomeness. (And then go and vote for the equivalent C++ request :-).
