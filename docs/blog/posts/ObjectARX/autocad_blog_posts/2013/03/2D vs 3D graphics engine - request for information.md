# 2D vs 3D graphics engine - request for information

发布日期: 2013-03-01

原始链接: https://adndevblog.typepad.com/autocad/2013/03/2d-vs-3d-graphics-engine-request-for-information.html

## 文章内容

By Stephen Preston
Kean Walmsley has posted a request for feedback from developers who are using graphics intensive AutoCAD applications. Basically, he wants to hear from you if your plug-in checks whether AutoCAD is running its 2D or 3D graphics engine and then makes use of that information.
Reading between the lines, this might make you think that the AutoCAD engineering team are considering some interesting things to do with the AutoCAD graphics engine, but I couldn't possibly comment on that :-).
Read Kean's request here.
