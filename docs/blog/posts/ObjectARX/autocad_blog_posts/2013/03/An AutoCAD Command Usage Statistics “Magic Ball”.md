# An AutoCAD Command Usage Statistics “Magic Ball”

发布日期: 2013-03-01

## 文章内容

By Daniel Du
As a practice of Windows Azure and WebGL, I did a simple project, creating an AutoCAD Command Usage Statistics “Magic Ball” on Cloud. Hopefully it gives your some inspirations of the possibility of AutoCAD + Cloud integration. The idea is to monitor user’s command usage while he is drafting and save it up to cloud, then view the statistics in web page with a rotatable ball, I call it “magic ball”, it does not look like a ball just because I am lazy not to draft much to use many AutoCAD commands.
