# Digitally signed vlx files are not working in AutoCAD 2018

发布日期: 2017-04-01

原始链接: https://adndevblog.typepad.com/autocad/2017/04/digitally-signed-vlx-files-are-not-working-in-autocad-2018.html

## 文章内容

By Madhukar Moogala
This post to make sure that it reaches all our Publisher community, for some reason digitally signed .vlx binaries are not working, i.e., the binaries are loading but execution commands returns an error.
We know the importance and impact of this behaviour, we escalated to Engineering, our development found the root cause and if all set it may be shipped in AutoCAD 2018 update 0.2.
Edit : Thanks to Daniel from Autodesk QA team for correction, instead of AutoCAD 2018 update 2 it should have read AutoCAD 2018.0.2 aka Update 0.2
