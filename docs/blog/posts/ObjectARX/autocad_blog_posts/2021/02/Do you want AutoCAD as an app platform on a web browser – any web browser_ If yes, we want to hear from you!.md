# Do you want AutoCAD as an app platform on a web browser – any web browser? If yes, we want to hear from you!

发布日期: 2021-02-01

原始链接: https://adndevblog.typepad.com/autocad/2021/02/do-you-want-autocad-as-an-app-platform-on-a-web-browser-any-web-browser-if-yes-we-want-to-hear-from-you.html

## 文章内容

The AutoCAD web app team is interested in understanding, in a deeper way, how Autodesk developers are creating solutions for showing drawings, CAD data, floorplans, and objects in a web-first fashion.  
Imagine if you could embed AutoCAD drawings and tools directly into your own applications. Help us to determine what to build in the future:
What if we were able to expose more AutoCAD capabilities as APIs for you to tailor to your company's needs?
What would you want or need, to allow you to build applications to view, edit, or place objects with precision?
What would you want to keep track of ownership or inventory?
Would you like to expand access to your drawing data? 
If you are a developer or Autodesk customer interested in assisting Autodesk with this product development research, please answer a few questions here (https://autodeskfeedback.az1.qualtrics.com/jfe/form/SV_0VbNxcd8uQZNH0i).
It will take a few minutes to answer the questions, please leave your contact information so that we can follow up with you about our research sessions.  
People who end up participating in the 60-minute remote research meeting, will receive a $75 gift card as a token of our appreciation.
