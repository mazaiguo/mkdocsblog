# Vote for Visual Studio x64 Edit-and-Continue

发布日期: 2012-11-01

原始链接: https://adndevblog.typepad.com/autocad/2012/11/vote-for-visual-studio-x64-edit-and-continue.html

## 文章内容

By Stephen Preston
A colleague in one of our product development teams pinged me today to ask for my support in voting up this request for Microsoft to implement x64 edit-and-continue. I’m sure this isn’t the first time this topic has been raised with Microsoft – but hopefully it will be the last . I went ahead and added my votes. And what’s a blog for, if not to nudge your readers into helping each other out once in a while .
I know of many programmers who use Windows 32-bit on their dev machines purely for this feature in Visual Studio. Make your vote count.
