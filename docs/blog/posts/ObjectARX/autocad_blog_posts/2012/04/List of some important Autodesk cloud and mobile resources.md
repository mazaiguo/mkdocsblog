# List of some important Autodesk cloud and mobile resources

发布日期: 2012-04-01

原始链接: https://adndevblog.typepad.com/autocad/2012/04/list-of-some-important-autodesk-cloud-and-mobile-resources.html

## 文章内容

By Gopinath Taget
You will find a bunch of developer videos for cloud computing at this location: www.autodesk.com/developcloud. Please check out the one called Cloud Computing with AutoCAD Part 1 – Integrating with Azure Compute Service for how to get started using Microsoft Azure with AutoCAD.
For a video using Amazon Web Services with AutoCAD, please check out my Autodesk University class An Overview of Cloud Computing.
A lot of Autodesk cloud services are available as a subscription program benefit. Also, if you use the URL www.autodesk.com/cloud, it will take you to the landing page for the Autodesk 360 cloud service. If your looking for a list of Autodesk mobile Apps, please check out the site Mobile Apps site.
Some of our other sites that might interest you:
https://www.autocadws.com/
http://www.123dapp.com/catch
http://www.autodesk.com/bim360
http://www.autodesk.com/plm360
http://usa.autodesk.com/green-building-studio/
We have a lot more going on in the cloud and mobile world with different teams at Autodesk and they are different stages of evolution. Please check back with us regularly for more updates on this.
