# Another AutoCAD .NET Wizard

发布日期: 2012-04-01

原始链接: https://adndevblog.typepad.com/autocad/2012/04/another-autocad-net-wizard.html

## 文章内容

By Stephen Preston
The DevTech team maintain a simple AutoCAD .NET Wizard for Visual Studio. Its a great learning aid for when we run training classes, its helpful for beginners, and makes it a lot simpler to debug your plug-ins if you're using Visual Basic/C# Express - but we deliberately keep it simple so we don't hide how the API works, or tie people in to a specific application architecture when they start programming that will make it hard to develop their own project templates later.
For those of you who yearn for something a little different, our friends over at TheSwamp have just spotted this alternative AutoCAD .NET Wizard - AcadNetAddinWizard. This is the first time I've come across 'spiderinnet1', and I've not tried this wizard myself - so I can't vouch for it personally -  but TheSwamp guys seem pretty keen. (As with anything you download from the interweb - use it at your own risk).
We'll continue to maintain our simple version. Kudos to spiderinnet for sharing this with the community.
And feel free to let us know if you have something posted somewhere that you'd like to share with the Autodesk developer community. Happy to mention it in this blog.
