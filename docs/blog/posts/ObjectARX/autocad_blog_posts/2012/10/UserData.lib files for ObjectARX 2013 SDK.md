# UserData.lib files for ObjectARX 2013 SDK

发布日期: 2012-10-01

原始链接: https://adndevblog.typepad.com/autocad/2012/10/userdatalib-files-for-objectarx-2013-sdk.html

## 文章内容

By Stephen Preston
If you’re one of the small number of ObjectARX developers who links to asiapi19.lib in your projects, then you’ll find that the 2013 SDK doesn’t include the additional UserData.lib file that this library depends on. You can download the missing files here (32-bit and 64-bit) and add them to your ObjectARX lib folders.
