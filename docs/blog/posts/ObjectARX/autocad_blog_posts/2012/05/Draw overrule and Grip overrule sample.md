# Draw overrule and Grip overrule sample

发布日期: 2012-05-01

原始链接: https://adndevblog.typepad.com/autocad/2012/05/draw-overrule-and-grip-overrule-sample.html

## 文章内容

By Virupaksha Aithal
Through this post I am sharing a nice sample on draw over rule and grip over rule. This sample was written in 2009/2010 by Stephen Preston for AutoCAD 2010, I have migrated the version to work with AutoCAD 2013.  The sample basically overrules the lines draw functionality and shows the same line as thermometer.  The sample also shows the procedure to use grip overrule.
To use the sample:
Download SGP_OverruleTest_XDict
build the sample
Start AutoCAD 2013, NETLOAD the sample
Draw a line
Issue command “ADDDATA” and provide required inputs.
