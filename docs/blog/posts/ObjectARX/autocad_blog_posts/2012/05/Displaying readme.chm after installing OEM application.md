# Displaying readme.chm after installing OEM application

发布日期: 2012-05-01

原始链接: https://adndevblog.typepad.com/autocad/2012/05/displaying-readmechm-after-installing-oem-application.html

## 文章内容

By Wayne Brill
Issue
I am following the instructions from the OEM 2011 Developer's Guide. My install works fine however the readme.chm file that I put in the Docs directory (as instructed) is not being displayed. Is there a way to get the readme.chm to automatically display if I have checked the "View Content" of the readme after the install?
Solution
Instead of creating a directory named "Docs", name the directory "Help". With this change the readme.chm file will be launched after the install if the check box is selected.
